Accessibility

Last updated 1 September 2026

This site is built with plain, semantic HTML and CSS. Nothing you need is behind JavaScript: the only script on the page is the Lightmorphic app launcher in the menu bar, and with it blocked every word, link and section still works. It's designed to work with a keyboard alone and with a screen reader, and to respect your device's reduced-motion preference.

What's been done

  • Every interactive element (links, the install code block) reachable and operable by keyboard, with a visible focus outline
  • Colour is never the only signal - status and emphasis are backed by text, not colour alone
  • Text and background colours checked for contrast against the dark palette the site uses
  • Headings are ordered properly so the page's structure makes sense read out by a screen reader
  • Decorative images (the dashboard mockup, icons) are hidden from assistive technology; the mockup has a plain-text description instead

Known limitations

The dashboard mockup on the homepage is a stylised illustration, not a screenshot of the real interface - it's marked decorative for screen readers rather than described in detail, since the real application's own accessibility is what actually matters day to day.

Report a barrier

If you hit an accessibility problem anywhere on this site, please say so at lightmorphic.com - what page, what you were trying to do, and what happened. It'll be looked at and fixed.

Lightmorphic Dockup

A self-hosted Docker Compose stack manager for home labs - every stack, its logs and its terminal in one window, with a real login and two-factor. Docker or Podman, no lock-in.

No cookies and no tracking. The only thing loaded from anywhere else is the Lightmorphic app launcher in the menu bar.
